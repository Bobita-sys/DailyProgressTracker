# 📌 Daily Progress Tracker

A web-based productivity application for managing **ToDo tasks** and tracking **habits**.  Users can register, log in, manage tasks, track streaks, set reminders, and view progress summaries. Built with Java Servlets, JSP, MySQL, HTML, CSS, Bootstrap, and JS.  
This project demonstrates **Java Web Programming** concepts with HTML, CSS, JavaScript, Servlets, JSP, and MySQL.

---

## 🚀 Current Features
- User Registration and Login (basic setup)
- Form validation with JavaScript and Java
- Exception handling in Java
- Modular project structure (MVC style)
